# around40 最終版の使い方

LisMの配置を基準にしつつ、左下3キーと右の@・括弧キーはaround40の現行位置・各レイヤーの動作を維持しています。

| 操作 | 動作 |
| --- | --- |
| J＋K同時押し | 左クリック |
| K＋L同時押し | 右クリック |
| クリックの同時押しを維持 | ドラッグ。両キーを離して解除 |
| 左Backspaceの真上 | マウス第4ボタン。既存BTTのアプリ一覧を開き、右トラックボールで選択 |
| 右端を単押し／長押し | F18（Typeless）／左Command |
| 左下の左から1番目 | Tab。長押しOption |
| 左下の左から2番目 | F5。長押しControl |
| 左下の左から3番目 | Command＋V（貼り付け） |
| 右内側の@キー | @。長押しで接続設定層 |
| ショートカット層の同じ@キー | 鍵括弧の既存マクロ |
| 数字層の同じ@キー | 丸括弧の既存マクロ |
| Q＋W同時押し | Esc。既存設定を維持 |
| Space＋Enter同時押しを維持しながらJ／K／L | 音量下げ／音量上げ／ミュート切替 |
| Space長押し／Enter長押し | 数字・記号層／ショートカット層 |
| カンマ長押し＋トラックボール | スクロール。既存設定を維持 |

JK／KLは基本層・マウス層で有効です。45ms以内の同時押しで反応し、両キーを離すまでクリックを維持します。音量操作のSpace＋Enterは60ms以内です。数字・ショートカット層のJ/K/L操作にはクリックコンボを重ねていません。

既存のオートマウス設定は残しています。ソース上はトラックボール入力でマウス層に入り、10秒で解除します。JとLの単独クリックも既存設定を維持しています。JK／KLのクリックはこの自動切替に依存しません。

## 書込み

1. 最新リリースから `around40-final.zip` を取得して展開する。
2. 左右それぞれをUSB接続し、メーカーの手順でブートローダーに入る。
3. 左には `around40-left.uf2`、右には `around40-right.uf2` をコピーする。
4. メモ帳などで、左下3キー、@・括弧、QWのEsc、F18、JK/KLのクリックとドラッグ、BTTのアプリ切替、音量を確認する。

`around40-settings-reset.uf2` は設定初期化用です。通常の更新では使いません。

UF2にはビルドした時点のキーマップを含みます。ZMK Studioで別の設定を保存している場合は、保存済みの配置が優先されることがあります。書込み後に変更が反映されない場合は、Studioの保存設定を確認してください。Bluetoothの初期化は通常更新の手順に含めていません。

BTT・TypelessのMac側設定はこのファームウェアに含まれません。BTTのマウス第4ボタンとTypelessのF18の既存割当を使います。

ZIP内の `SOURCE_COMMIT.txt` にソースのコミット、`SHA256SUMS.txt` にUF2のハッシュを記録しています。左右・初期化用の3つがすべてビルド成功した場合だけリリースを作成します。
